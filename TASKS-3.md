# Задачи 20–30: ветка МСФО

Основание — разбор шести комплектов отчётности: Автодор (квазисуверен,
промежуточная, сканы), Сегежа (стресс, специального назначения), ФосАгро
(норма, запятая как разделитель разрядов), ЛСР (девелопер, эскроу в сноске),
Европлан (лизинг, неклассифицированный баланс), Норникель (доллары, три
периода, раскрываемая).

## Принятые решения, действующие на всю ветку

| Решение | Содержание |
|---|---|
| Периметр | Нефинансовые организации. Финансовая отчётность распознаётся и отклоняется с внятной причиной, не оценивается |
| Валюта | Только рублёвая. Иная валюта — отказ с указанием причины |
| Архитектура | Единая система с РСБУ. Источник (`rsbu` / `ifrs`) — обязательное измерение. Смешение источников в одном показателе запрещено |
| Приоритет | Для группы база — МСФО, РСБУ как более свежий срез и для сверки. Для юрлица без консолидированной отчётности база — РСБУ |
| Приём | Ручная подача — основная ветка. Автоматическая загрузка по ИНН — задача 30, после того как ручная работает целиком |
| Текст | Сборка расчётом, как в РСБУ. Модель — опция `--llm` |

## Что учитывать из опыта РСБУ

Эти три правила выведены на РСБУ и действуют здесь с первого дня, а не
открываются заново:

- **«Не раскрыто ≠ 0»** — в МСФО прочерков больше, чем в РСБУ, и статья,
  отсутствующая у одного эмитента, есть у другого. Отсутствие статьи
  не означает нулевого значения.
- **«Ноль срабатываний неотличим от невыполненного контроля»** — каждый
  новый контроль сообщает число проверенных объектов.
- **«Свобода не исчезает, она переезжает»** — при выносе раздела в расчёт
  проверяются соседние.

## Задача 20 — Источник как измерение

```
Прочитай CLAUDE.md и таблицу точек связывания. Подготовь модель данных
к двум источникам.

1. Поле source ('rsbu' | 'ifrs') во всех таблицах фактов и показателей:
   src_file, fact_report, metric_value, assessment, assessment_metric,
   assessment_group, assessment_signal. Уникальные ключи расширяются
   источником.

2. Ни один показатель не рассчитывается смешением источников. Контроль:
   при расчёте все входные величины обязаны иметь один source, иначе
   not_calculable с причиной 'смешение источников'.

3. Правило приоритета: для организации с консолидированной отчётностью
   базой оценки является МСФО, показатели РСБУ рассчитываются и хранятся,
   но в скоринг не идут. Для организации без МСФО база — РСБУ.
   Правило в methodology, не в коде.

4. Расхождение между источниками — самостоятельный сигнал. Заведи
   заготовку: показатель, рассчитанный по обоим источникам за сопоставимый
   период, расходится сверх порога. Формулировку и порог пока не задавай,
   нужен набор данных.

5. Седьмая точка связывания: report.yaml говорит «строки бухгалтерской
   отчётности приведены с их кодами». Для МСФО кодов строк нет — есть
   позиции унифицированной модели. Разведи формулировку по источнику.

Критерий: существующие прогоны по РСБУ дают тот же результат,
регрессионный набор зелёный.
```

## Задача 21 — Унифицированная модель статей

```
methodology/ifrs_lines.yaml — модель статей консолидированной отчётности.

Устройство: ядро плюс существенные специфические статьи.

ЯДРО — около 28 позиций, подтверждённых на четырёх нефинансовых эмитентах:
основные средства, активы в форме права пользования, нематериальные активы,
гудвил, инвестиции в ассоциированные и совместные предприятия, отложенные
налоговые активы, прочие внеоборотные; запасы, торговая и прочая
дебиторская задолженность, авансы выданные, денежные средства и эквиваленты,
прочие оборотные; кредиты и займы долгосрочные и краткосрочные,
обязательства по аренде долгосрочные и краткосрочные, отложенные налоговые
обязательства, торговая и прочая кредиторская задолженность, оценочные
обязательства, налоги к уплате, авансы полученные; акционерный капитал,
добавочный капитал, накопленная прибыль или убыток, накопленный прочий
совокупный доход, неконтролирующие доли; итоги разделов и валюта баланса.
ОПУ и ОДДС — отдельными блоками.

СПЕЦИФИЧЕСКИЕ: статья, превышающая порог существенности (5 % валюты
баланса), никогда не сворачивается в «прочее». Она выносится отдельной
позицией с кодом, присвоенным при подтверждении. Основание: у Автодора
85 % активов в двух статьях, которых нет ни у кого другого (задолженность
Принципала, затраты в интересах Принципала), у Сегежи обязательства
по опционным соглашениям — 30 % краткосрочных обязательств, у ЛСР эскроу.

Справочник синонимов: одна позиция — несколько наименований.
«Итого оборотные активы» / «Итого краткосрочные активы» / «Итого оборотных
активов» / «Оборотные активы» — одна позиция. Синонимы с пометкой,
у какого эмитента встречены.

Тесты: все позиции состава итогов существуют; синонимы не пересекаются
между позициями.
```

## Задача 22 — Приём файла и определение параметров

```
sources/ifrs_inbox.py. До извлечения чисел определяются шесть параметров,
каждый детерминированно, каждый с отказом при неопределённости.

1. ТИП ДОКУМЕНТА. Годовой отчёт эмитента (100-300 страниц, стратегия, ESG)
   финансовой отчётностью не является. Признак: наличие форм с заголовками
   «отчёт о финансовом положении», «отчёт о прибыли или убытке». Не найдено —
   отказ с причиной «это не консолидированная финансовая отчётность,
   вероятно годовой отчёт эмитента».

2. ВАЛЮТА. Из шапки формы («в миллионах российских рублей», «млн руб.»,
   «в долларах США»). Не рубль — отказ, организация вне периметра.

3. ЕДИНИЦА. Млн / тыс. руб. Из шапки. Не определена — отказ.

4. РАЗДЕЛИТЕЛЬ РАЗРЯДОВ. Определяется НА УРОВНЕ ДОКУМЕНТА, не числа.
   У ФосАгро запятая: «663,888» = 663 888 млн руб. Существующая to_decimal
   трактует запятую как десятичный разделитель и даст ошибку в 1000 раз,
   которую не поймает ни один контроль: баланс сойдётся, коэффициенты будут
   верны. Алгоритм: собрать выборку чисел, определить конвенцию по
   распределению групп цифр, применить ко всему документу. Неоднозначность —
   карантин, не угадывание.

5. ЧИСЛО ПЕРИОДОВ. Переменное: Норникель даёт три, остальные два.
   Модель принимает N периодов.

6. ВИД ОТЧЁТНОСТИ: полная / раскрываемая / специального назначения /
   промежуточная по IAS 34. Сокращённые версии содержат не все примечания;
   вид фиксируется и попадает в ограничения анализа.

Плюс признак финансовой организации: неклассифицированный баланс без
деления на оборотные и внеоборотные, статья «чистые инвестиции в лизинг»
или банковский план счетов. Отказ с причиной «финансовая организация,
отдельная методика не реализована».

Плюс признак скана: нет текстового слоя. Отказ с причиной «требуется OCR»,
сам OCR — задача отложенная. Основание: промежуточная отчётность Автодора —
сканы, pdftotext извлекает 26 байт.
```

## Задача 23 — Извлечение основных форм и экран сверки

```
1. Извлечение баланса, ОПУ, ОДДС и отчёта об изменениях капитала
   в унифицированную модель. Позиция опознаётся по наименованию через
   справочник синонимов.

2. Итоги разделов не всегда подписаны: у Норникеля итог внеоборотных
   активов — просто число без наименования, у ФосАгро слово «Внеоборотные
   активы» служит и заголовком раздела, и подписью итога. Контроль
   сходимости не может опираться на наименование: опирайся на структуру —
   последняя числовая строка перед следующим заголовком, проверяемая
   на равенство сумме предшествующих.

3. Обязательное извлечение текста НЕПОСРЕДСТВЕННО ПОД формой, вне таблицы.
   У ЛСР сноской под балансом: в состав денежных средств не включены
   средства на счетах эскроу 217 501 млн руб. Парсер таблиц её не увидит,
   а без неё показатели ликвидности читаются неверно.

4. Контроли: актив = пассив; сходимость разделов; цепочка прибыли;
   совпадение сравнительных данных с предыдущей отчётностью того же
   эмитента, если она в базе.

5. ЭКРАН СВЕРКИ. Подтверждённая человеком таблица играет роль справочника
   кодов: числа приходят из проверенного источника, каждое утверждение
   ссылается на позицию модели. Это сохраняет инвариант при отсутствии
   регламентированных кодов строк.

   Режим автоматического прохождения: если все контроли пройдены, все
   позиции опознаны справочником, специфических статей сверх порога нет
   и вид отчётности полный — подтверждение не требуется, извлечение
   принимается автоматически с пометкой в журнале. Основание: при
   обязательном ручном подтверждении автоматический скрининг ста эмитентов
   невозможен, а маршрутизация — цель всей ветки.

   Ручное подтверждение обязательно при: срабатывании любого контроля,
   неопознанной позиции, специфической статье сверх порога, виде отчётности
   кроме полного.
```

## Задача 24 — Примечания

```
Без примечаний расчёт по МСФО методологически недопустим. Основание:
у Автодора в ОПУ финансовые расходы 131 млн, а в примечании — общая сумма
26 430 млн, из которых 26 024 покрыты целевым финансированием Принципала.
Покрытие процентов по основным формам — 7,5, реальная стоимость долга
в 200 раз выше видимой.

Восемь обязательных примечаний, извлекаются по ЗАГОЛОВКУ, не по номеру:
нумерация плавает (у Автодора заёмные средства — примечание 19
в полугодовой и 17 в квартальной).

1. Заёмные средства: структура по инструментам, ставки, сроки погашения,
   валюты, обеспечение, ковенанты и их соблюдение.
2. Финансовые доходы и расходы: проценты начисленные ДО вычета субсидий
   и капитализации.
3. Амортизация — для EBITDA. Из ОДДС или сегментного примечания.
   Нет амортизации — Чистый долг/EBITDA не рассчитывается, суррогаты
   запрещены (правило действует с РСБУ).
4. Состав группы и периметр консолидации.
5. Связанные стороны: остатки и обороты.
6. Условные обязательства, гарантии, поручительства, судебные дела.
7. Денежные средства: ограничения в использовании, эскроу.
8. События после отчётной даты.

Нетекстовые сигналы из примечаний — отдельно. У Сегежи: превышение
краткосрочных обязательств над активами на 77 003 млн; ковенанты
по опционным соглашениям не соблюдены; долг перед кредитором
из недружественных стран переведён в краткосрочные из-за нарушения
ковенант; опционы обеспечены залогом долей в трёх производственных
дочерних предприятиях; займы акционера субординированы до 2033 года.
Ничего из этого не выводится из основных форм.
```

## Задача 25 — Аудиторское заключение как признак

```
Модифицированное мнение — норма, а не исключение: два эмитента из шести.

Извлекается и становится машинным признаком:
- тип вывода: безоговорочный / с оговоркой / отрицательный / отказ;
- наличие раздела о существенной неопределённости непрерывности
  деятельности;
- наличие раздела «важные обстоятельства»;
- текст основания оговорки;
- аудитор и дата.

Тип мнения — БЛОКИРУЮЩИЙ признак, меняющий интерпретацию всех показателей,
а не справочная строка. Основание: у Автодора вывод с оговоркой — резерв
занижен, чистая прибыль завышена не менее чем на 11 908 млн при заявленной
прибыли 50 млн. Система, читающая только цифры, напишет «прибыль 50 млн,
положительная динамика». Это ложный вывод при формально верном числе.

Правила:
- при выводе с оговоркой показатели, затронутые оговоркой, помечаются
  и в скоринг не идут либо идут с понижением уверенности — решение
  по составу затронутых показателей принимает человек на экране сверки;
- раздел о непрерывности деятельности — стоп-фактор;
- отрицательное мнение или отказ — оценка не формируется.
```

## Задача 26 — Тип эмитента и применимость стоп-факторов

```
Стоп-факторы РСБУ на МСФО механически не переносятся.

Основание: итого капитала у Автодора −111 млн, у Сегежи −15 008 млн.
Формальное условие одно, экономический смысл противоположный. У Автодора
капитала нет по устройству: прибыль ежегодно реинвестируется Принципалу,
рейтинги АА(RU)/ruAA+. У Сегежи — накопленный убыток 138 955 млн
и существенная неопределённость непрерывности деятельности.

Введи предварительный признак типа эмитента:
- обычный корпоративный;
- квазисуверенный / проектный (создан законом, учредитель — государство,
  целевое финансирование в структуре, отсутствие капитала по устройству);
- девелоперский (эскроу, проектное финансирование);
- финансовый (вне периметра, отказ).

От типа зависит применимость каждого стоп-фактора и состав показателей.
Признак определяется машинно по набору условий, но подтверждается
человеком на экране сверки — это классификация с последствиями для оценки.

У девелопера отдельно: показатели ликвидности без учёта эскроу
не рассчитываются. Текущая ликвидность ЛСР формально 4,15, но запасы
310 977 млн — незавершённое строительство, а 217 501 млн на эскроу
компании недоступны.
```

## Задача 27 — Показатели и скоринг

```
Состав показателей подбирается ПОД БУДУЩУЮ МАРШРУТИЗАЦИЮ, а не «полный
набор кредитных метрик». Вопрос к каждому: участвует ли он в решении,
нужен ли человек. Не участвует — идёт в приложение, не в скоринг.

Обязательно:
- Чистый долг / EBITDA (EBITDA считается, амортизация из примечаний);
- покрытие процентов ПО РЕАЛЬНОЙ стоимости долга из примечаний;
- график погашения: доля долга к погашению в ближайшие 12 месяцев,
  покрытие денежными средствами;
- валютная структура долга против валютной структуры выручки;
- соблюдение ковенант;
- ликвидность с поправкой на ограниченные в использовании средства;
- FFO / Долг;
- рентабельность и оборачиваемость — в приложение, в скоринг не идут.

Пороги: для Чистый долг/EBITDA и покрытия процентов они общеприняты
и значительно менее спорны, чем для коэффициентов РСБУ. Калибруй
со ссылкой на методологии рейтинговых агентств, фиксируй origin.
Правило «признака нет — тезиса нет» действует.

Промежуточная отчётность: аннуализация обязательна и обязательно явно
помечена в документе. Молчаливое умножение на два запрещено.
```

## Задача 29 — Регрессионный набор МСФО

```
Состав: шесть разобранных эмитентов плюс 10-15 добранных, покрытие —
по типу эмитента, виду отчётности, типу аудиторского мнения, наличию
специфических статей сверх порога, полноте примечаний.

Два контура, как в РСБУ: быстрый без модели, полный с генерацией.
Метрики: доля извлечений, прошедших автоматически против требующих
подтверждения; доля позиций, опознанных справочником; срабатывания
```
