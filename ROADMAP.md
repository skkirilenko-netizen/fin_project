# Дорожная карта

Утверждена: 22.09.2026. Правится только диффом и с согласия владельца проекта.
Отметки о выполнении критериев ставит исполнитель, с коммитом и числами в замере.

## Цель

Система мониторинга эмитентов ценных бумаг, которая каждый день отвечает
на вопрос «что изменилось и кем заняться», а затем — разбор любой организации
по запросу.

Два режима одной системы:

| | Мониторинг | Разбор по запросу |
|---|---|---|
| Кто | эмитенты облигаций и акций | любая организация по ИНН |
| Когда | ежедневно, по расписанию | по запросу аналитика |
| Выход | список наблюдения, отчёт изменений, карточка эмитента | заключение по организации |
| Слои | отчётность, события, рейтинги, рынок, рефинансирование | в основном отчётность |

## Контур

Система работает во внешнем контуре. Внутренний контур закрыт: данные из него
наружу не выходят, его названия, код и данные в репозиторий не попадают.
Методика из внутренних наработок переносится только словами.

## Источники

| Слой | Источник |
|---|---|
| Отчётность годовая | Cbonds МСФО и РСБУ; ГИР БО — первоисточник РСБУ; PDF — для разбора |
| Отчётность промежуточная | Cbonds |
| События | дефолты по выпускам (Cbonds), сектор повышенного риска (ISS), журнал ручных решений |
| Рейтинги | Cbonds, ежедневный снимок (история у подписки закрыта) |
| Рынок | Мосбиржа ISS: история торгов, кривая ОФЗ, индексы, дивиденды |
| Рефинансирование | потоки и оферты (Cbonds) |
| Связи | поручители и оференты (Cbonds); поле группы — только справочно |

## Часть первая. Эмитенты ценных бумаг

### Фаза 1. Охват облигаций — в работе

Все эмитенты с облигациями в обращении (702 на 22.09.2026).

- [ ] события и рейтинги — на всех эмитентах, независимо от стандарта отчётности
- [ ] маршрут по РСБУ для эмитентов без МСФО: долг 1410 + 1510, денежные средства 1250,
      ликвидность 1200/1500, автономия 1300/1700, вывод по границе через 2200
- [ ] холдинги (ОКВЭД 64.20, 70.10) на одной РСБУ — не мягче «Внимания»
- [ ] эмитенты без отчётности — маршрут по событиям и рейтингам с пометкой
- [ ] 46 эмитентов с МСФО у агрегатора, но вне списка, — разложены по причинам
- [ ] строки без выпусков в обращении — отдельным разделом, вне сводных долей
- [ ] третья экспертная проверка списка

**Критерий:** каждый эмитент в корзине или в «Установить статус»; ни один не выпал
молча; экспертная проверка не нашла эмитентов с известными проблемами в «Без внимания».

### Фаза 2. Ежедневный мониторинг

- [ ] прогон по расписанию целиком: рейтинги, события, сектор риска, маршрут, выгрузка
- [ ] отчёт «что изменилось со вчера»: кто сменил корзину, по какому основанию
- [ ] история корзин по каждому эмитенту
- [ ] журнал прогонов: что загружено, что отказало, сколько проверено
- [ ] проверка здоровья источников: отказ источника виден, а не молчит
- [ ] резервная копия снимков вне ноутбука

**Критерий:** десять дней подряд без ручного вмешательства; отчёт изменений читается
за пять минут.

После фазы 2 — **материалы для руководства**, не дожидаясь конца дорожной карты.

### Фаза 3. Рынок облигаций

Методика — из рабочей модели владельца проекта, реализация заново на данных ISS.

- [ ] правило сравнимости: флоатеры, линкеры, валютные, неизвестный купон — не спред
      кредитного риска; бумаги с офертой — к оферте
- [ ] G-спред к кривой ОФЗ с учётом дюрации; Z-спред биржи — для сверки;
      формула кривой сверена с опубликованными точками
- [ ] очистка: выпуск × дата с весом объёма сделок, затем эмитент;
      обрезка 0,1 / 99,9 перцентиля внутри дня, потолок 20 000 б.п.
- [ ] ориентир — 25-й перцентиль спредов ликвидного ядра на дату, не индекс
- [ ] лестница кратности к ориентиру, скорость расширения, «K из N»
      (7 из 10 и 14 из 20 для системно значимых)
- [ ] зона дефолта — цена в % номинала, где доходность теряет смысл
- [ ] ежедневный расчёт; ISS — архив, сырой кэш можно чистить

**Критерий:** пороги обоснованы распределением, а не событиями; упреждение измерено
на календаре событий.

### Фаза 4. Акции

- [ ] акции как сигнал для эмитентов облигаций с торгуемыми акциями
- [ ] доходность с учётом дивидендов; отклонение от ожидаемого при бете, а не от индекса
- [ ] эмитенты котировального списка без облигаций — со своим толкованием корзин:
      просадка, волатильность, ликвидность, смена уровня листинга, приостановка торгов

**Критерий:** дивидендный разрыв не читается как падение; эмитенты без облигаций
маршрутизируются по своим правилам.

### Фаза 5. Промежуточная отчётность

- [ ] замер на календаре событий: увидела бы промежуточная отчётность дефолты
      раньше годовой и на сколько
- [ ] при подтверждении — скользящие двенадцать месяцев для потоков, баланс на дату
- [ ] сигналы изменения: денежные средства, краткосрочный долг, скользящая EBITDA
- [ ] период — часть ключа комплекта; правило выбора годового и промежуточного объявлено
- [ ] неаудированная промежуточная отчётность — пониженная уверенность в основании

**Критерий:** замер показал выигрыш в упреждении — или честно не показал, и фаза закрыта.

### Фаза 6. Матрица слоёв

- [ ] отчётность, события, рынок, рефинансирование — в одной корзине
- [ ] расхождение рынка и отчётности как самостоятельный сигнал
- [ ] калибровка порогов отчётности по накопленной истории рейтингов и событий

**Критерий:** выявляемость и прирост матрицы выше, чем у любого слоя отдельно.

### Фаза 7. Карточка эмитента

- [ ] одна страница на эмитента: история корзин, основания, график спреда и цены, события
- [ ] переход к заключению по PDF для эмитентов в «Разборе»

**Критерий:** аналитик понимает эмитента, не открывая источники.

### Критерий выхода — «эмитенты закрыты»

Переход к части второй — когда выполнены все пять:

- [ ] **охват** — каждый эмитент ценных бумаг в обращении в круге, с корзиной или статусом
- [ ] **качество** — на календаре событий за последние двенадцать месяцев ни одного дефолта
      в «Без внимания» до события; выявляемость, прирост и упреждение измерены и записаны
- [ ] **устойчивость** — ежедневный цикл без вмешательства не меньше месяца
- [ ] **экспертиза** — экспертная проверка не находит критичных дефектов два раза подряд
- [ ] **документация** — методика описана так, что её можно передать другому аналитику

## Часть вторая. Кредиты по запросу

### Фаза 8. Разбор по любому ИНН

- [ ] режим по запросу: ИНН на входе, заключение на выходе
- [ ] отчётность компаний без ценных бумаг — выгрузка из ГИР БО или СПАРК в папку приёма
- [ ] решение по упрощённой отчётности: отдельная ветвь методики или отказ в классе
- [ ] ввод параметров кредита вручную (сумма, срок, ставка, график) и сопоставление
      платежей с денежным потоком заёмщика
- [ ] группа заёмщика — вручную
- [ ] события банкротства — при приемлемом доступе к ЕФРСБ

**Границы:** категорию качества ссуды система не присваивает — это суждение аналитика.
Перечень запрашиваемых ИНН — сведения надзора: хранится локально и пакетом во внешние
сервисы не отправляется.

## Принципы

1. **Факт и прогноз разделены.** Дефолт по выпуску — основание маршрута; календарь событий
   для проверки качества в расчёте не участвует.
2. **Пороги — из распределения, не по событиям.** Иначе проверка всегда идеальна.
3. **Ни один эмитент не исчезает молча.** Любой выход — с причиной в журнале исключений.
4. **Одно обстоятельство — одно решение о маршруте.**
5. **Ручные решения — в журнал**, с автором, основанием и сроком действия.
6. **Одна точка печати** для каждой величины и единицы.
7. **Ноль неотличим от невыполненного контроля** — у каждой проверки знаменатель.
8. **Прежде чем объявить аномалию свойством эмитента — опровергни, что она наша.**
9. **Одно изменение за раз**: новый слой не вводится одновременно с другим.

## Бэклог, без срока

- долг девелопера за вычетом проектного финансирования, покрытого эскроу
- неконсолидированная МСФО как третий стандарт
- справочник групп с подтверждёнными финансовыми связями — вручную
- статус «под наблюдением» по рейтингам — источником недоступен, пока журнал ручных решений
- новости: запрос в Cbonds о методах сообщений эмитентов, уведомления ISS
- ухудшение ЧОК вместо знака — сигнал по изменению, а не по уровню
- распознавание сканов (первый случай — страница 9 отчётности Автодора)
- перенос с ноутбука на внешний сервер
