# Дорожная карта

Утверждена: 22.09.2026. Правится только диффом и с согласия владельца проекта.
Отметки о выполнении критериев ставит исполнитель, с коммитом и числами в замере.

## Цель

Система мониторинга эмитентов ценных бумаг, которая каждый день отвечает
на вопрос «что изменилось и кем заняться», а затем — разбор любой организации
по запросу.

Два режима одной системы:

| | Мониторинг | Разбор по запросу |
|---|---|---|
| Кто | эмитенты облигаций и акций | любая организация по ИНН |
| Когда | ежедневно, по расписанию | по запросу аналитика |
| Выход | список наблюдения, отчёт изменений, карточка эмитента | заключение по организации |
| Слои | отчётность, события, рейтинги, рынок, рефинансирование | в основном отчётность |

## Контур

Система работает во внешнем контуре. Внутренний контур закрыт: данные из него
наружу не выходят, его названия, код и данные в репозиторий не попадают.
Методика из внутренних наработок переносится только словами.

## Источники

| Слой | Источник |
|---|---|
| Отчётность годовая | Cbonds МСФО и РСБУ; ГИР БО — первоисточник РСБУ; PDF — для разбора |
| Отчётность промежуточная | Cbonds |
| События | дефолты по выпускам (Cbonds), сектор повышенного риска (ISS), журнал ручных решений |
| Рейтинги | Cbonds, ежедневный снимок (история у подписки закрыта) |
| Рынок | Мосбиржа ISS: история торгов, кривая ОФЗ, индексы, дивиденды |
| Рефинансирование | потоки и оферты (Cbonds) |
| Связи | поручители и оференты (Cbonds); поле группы — только справочно |

### Фаза 3. Рынок облигаций

Методика — из рабочей модели владельца проекта, реализация заново на данных ISS.

- [x] правило сравнимости: флоатеры, линкеры, валютные, неизвестный купон — не спред
      кредитного риска; бумаги с офертой — к оферте
      (`market.yaml`, блок `comparability`; каждое правило объявляет полем
      `breaks`, ломает ли оно доходность или и цену)
- [x] G-спред к кривой ОФЗ с учётом дюрации; Z-спред биржи — для сверки;
      формула кривой сверена с опубликованными точками
      (кривая берётся опубликованными точками с интерполяцией; формула
      по параметрам не воспроизводится — угаданная постоянная дала бы кривую
      настоящего вида и неверную. Z-спред биржи есть только с 12.2025)
- [x] очистка: выпуск × дата с весом объёма сделок, затем эмитент;
      обрезка 0,1 / 99,9 перцентиля внутри дня, потолок 20 000 б.п.
- [x] ориентир — 25-й перцентиль спредов ликвидного ядра на дату, не индекс
- [x] лестница кратности к ориентиру, скорость расширения, «K из N»
      (ступени переставлены на перцентили распределения: круглые кратности
      1,5–5× отсекали от 42 до 74 % рынка, то есть мерили фон. Расширение
      и отклонение от собственной нормы **замерены и отвергнуты** — прирост
      0,9× и 2,1×, — и объявлены недействующими вместе с числами)
- [x] зона дефолта — цена в % номинала, где доходность теряет смысл
- [x] ежедневный расчёт; ISS — архив, сырой кэш можно чистить

**Критерий:** пороги обоснованы распределением, а не событиями; упреждение измерено
на календаре событий.

**Выполнено 24.09.2026.** Пороги обоснованы распределением: у каждой ступени
объявлено, какую долю рынка она отсекает и на какой перцентиль кратности
приходится; события в обоснование не идут — они проверяют упреждение. Замер —
`eval/market_lead_run.py` (`make market-lead`), круг 977 эмитентов
справочника, 482 с рыночным рядом, 37 событий в окне доставки, базовая доля
6,6 %.

**В маршрут вошли три основания из шести измеренных.** Цена ниже 60 %
номинала — прирост 6,6× при упреждении 43 дня и выявляемости 96,9 %;
кратность на p99 с подтверждением «5 из 10» — 3,6× при 139 днях и 81,2 %;
кратность на p95 — 2,4×, корзина «Внимание» подгруппой рынка. Расширение
спреда (0,9×) и отклонение от собственной нормы (2,1×) отвергнуты. Вклад
слоя в список: рыночное основание **открыло 84 эмитента, ещё у 98 подняло
тяжесть** к уже стоявшим основаниям.

**Упреждение измерено с четырьмя поправками, каждая из которых меняла ответ**:
слои сравниваются на общем окне наблюдения; основание, стоявшее с первого
наблюдавшегося дня, упреждением не считается; срабатывание после события
не считается поимкой; событие позже последнего доставленного дня в меру
разрыва торгов не идёт. После них видно главное: **упреждение даёт только
рынок** — у появившегося основания отчётности прирост 1,1×, у рейтингов 2,9×,
у цены 7,5×.

Карточка эмитента получила график спреда и цены — то, что стояло за фазой 3
в фазе 7.

### Фаза 4. Акции

- [x] акции как сигнал для эмитентов облигаций с торгуемыми акциями
      — **замерено и закрыто**: мерить не на чем, см. ниже
- [x] доходность с учётом дивидендов; отклонение от ожидаемого при бете,
      а не от индекса — **правила выведены, применять их не к чему**:
      дивидендов не отдаёт ни один из двух источников
- [x] эмитенты котировального списка без облигаций — **не добавляются**:
      их четыре, и предмет вопроса ради четверых не меняется

**Критерий:** дивидендный разрыв не читается как падение; эмитенты без облигаций
маршрутизируются по своим правилам.

**Закрыто 24.09.2026 решением владельца по разведке**
(`eval/moex_shares_probe.py`). Фаза закрыта в задуманном виде: слой акций
на нашем круге событий **не измерим**.

Числа разведки. Торгуемых акций 275 у 230 эмитентов; в нашем круге из них
210, и облигации в обращении есть у **70**. Вне круга 20 эмитентов, из них
в котировальном списке первого и второго уровней — **4**. И решающее:
из 37 событий в окне доставки акции есть у **одного** эмитента. Одно
наблюдение — не замер, а четыре эмитента — не повод менять предмет вопроса.

**Связь эмитентов нашлась по ИНН, и её даёт сама биржа**: поиск ISS отдаёт
`emitent_inn` у каждой бумаги, сопоставлять по наименованию не нужно вовсе.
**Дивидендов не отдаёт ни один источник**: публичный ISS отвечает
«Информация доступна только подписчикам», у Cbonds `get_stocks_full`
и `get_stocks_dividends_v2` — «invalid resource name». Без них доходность
с учётом дивидендов не считается ничем, и дивидендный разрыв читался бы
как падение цены.

**Два следствия оставлены, и оба не про маршрут:**

- [x] **снимок уровня листинга — ежедневно, с 24.09.2026.** Истории смен
      уровня у источника нет вовсе, и не начав копить, мы не получим её
      никогда — тот же случай, что с рейтингами. Смена уровня и приостановка
      торгов — событие того же рода, что перевод в сектор риска; когда
      накопится, померим и решим;
- [x] **цена акции в карточке — справочно**, без основания и без участия
      в маршруте: аналитику, разбирающему эмитента, она полезна, а измерять
      её нечем. Сравнение — с ценовым IMOEX, а не с MCFTR: цену сравнивают
      с ценой, иначе дивиденды индекса войдут в сравнение, а дивиденды
      бумаги — нет.

## Принципы

1. **Факт и прогноз разделены.** Дефолт по выпуску — основание маршрута; календарь событий
   для проверки качества в расчёте не участвует.
2. **Пороги — из распределения, не по событиям.** Иначе проверка всегда идеальна.
3. **Ни один эмитент не исчезает молча.** Любой выход — с причиной в журнале исключений.
4. **Одно обстоятельство — одно решение о маршруте.**
5. **Ручные решения — в журнал**, с автором, основанием и сроком действия.
6. **Одна точка печати** для каждой величины и единицы.
7. **Ноль неотличим от невыполненного контроля** — у каждой проверки знаменатель.
8. **Прежде чем объявить аномалию свойством эмитента — опровергни, что она наша.**
9. **Одно изменение за раз**: новый слой не вводится одновременно с другим.
