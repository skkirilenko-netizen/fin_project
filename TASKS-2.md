## Задача 13 — Единая точка округления

```
(3.2.2) В тексте по Магниту: "рентабельность активов снизилась с 0,41
до 0,31 (изменение 0,11)". Разность отображаемых уровней — 0,10.
Заявленный темп −25,6 % из 0,41 и 0,31 не выводится, получается −24,4 %.

Причина: дельты считаются по полной точности, уровни отображаются
округлёнными. Формально ошибки нет, документ арифметически несогласован.

Введи единую точку округления на границе расчётного слоя:
- каждый показатель имеет в metrics.yaml разрядность отображения;
- округление выполняется один раз, при выгрузке из metric_value;
- дельты и темпы считаются от округлённых значений, не от исходных;
- в контекст модели, в текст документа и в приложение идут одни
  и те же округлённые величины.

Это отменяет прежнее решение подавать в контекст точные значения —
оно принималось для того, чтобы текст и приложение не расходились,
и единая точка округления решает ту же задачу надёжнее.

Добавь контроль: заявленное в тексте изменение обязано равняться
разности отображаемых уровней. Расхождение — блокирующее нарушение.
```

## Отдельно: ветвь методики для упрощённой отчётности

Не оформлено задачей, требует вашего решения до постановки.

Экспертная оценка отмечает, что у двух организаций из трёх класс
не сформирован при полном комплекте форм упрощённой отчётности,
и ставит вопрос о применимости методики к субъектам малого
предпринимательства.

Правило доминирования группы (класс не присваивается при эффективном
весе группы выше 0,5) само по себе верно — именно оно предотвратило
присвоение Магниту класса B на четырёх показателях. Но на упрощённых
формах пять групп недостижимы конструктивно, и система будет
отказывать в оценке основной массе малых предприятий.

Два варианта:

**A. Отдельная ветвь методики.** Для упрощённой отчётности — свой состав
групп, свои веса, своя шкала классов, явно помеченная как несопоставимая
с оценкой по полным формам. Класс присваивается, но в другой системе
координат.

**B. Оставить отказ.** Система честно отказывает в интегральной оценке,
выдавая показатели, флаги и сигналы без класса. Для надзорного
применения приемлемо; для оценки контрагентов малого бизнеса —
существенное ограничение области применения.

Выбор определяется тем, кто основной пользователь системы.
